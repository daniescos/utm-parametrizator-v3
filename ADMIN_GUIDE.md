# Admin Guide

This version has no admin panel in the app itself — UTM rules (fields, dropdown options,
conditional logic) are edited directly in `public/config.json` and published via git.

See **[MANUAL.md](./MANUAL.md)** for the full step-by-step guide with examples for every
rule type (filter, visibility, required, transform, warning).

For deployment steps, see [DEPLOY.md](./DEPLOY.md).
